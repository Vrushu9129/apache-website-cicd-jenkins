# 🚀 Automated Website Deployment Using Jenkins & Apache

## 📌 Project Overview

This project demonstrates a CI/CD workflow for deploying a static website to an Apache Web Server hosted on AWS EC2.

The source code is maintained in GitHub, while Jenkins is used to retrieve the latest changes and execute the deployment workflow.

## 🛠️ Technology Stack

- **Cloud:** Amazon Web Services (AWS EC2)
- **Version Control:** Git & GitHub
- **CI/CD Tool:** Jenkins
- **Web Server:** Apache HTTP Server
- **Frontend:** HTML5, CSS3
- **Operating System:** Linux / Ubuntu

## 🔄 CI/CD Workflow

GitHub → Jenkins → Apache Web Server → Live Website

### How It Works

1. The website source code is stored in GitHub.
2. Jenkins retrieves the latest code from the repository.
3. The deployment job updates the website files on the Apache server.
4. Apache serves the updated website to users.
5. The deployment is verified through the EC2 public IP address.
